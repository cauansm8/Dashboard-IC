# Visualização Interativa de Dados Coletados por Plataformas de Força

Professor: Danilo Medeiros Eler

 Essa pesquisa tem como objetivo desenvolver uma abordagem de análise visual dos dados para
apoiar profissionais das Ciências Biológicas e da Saúde na interpretação de informações
provenientes de plataformas de força (PF), especialmente no contexto do controle postural
estático. 
 A motivação surge da dificuldade enfrentada por usuários não familiarizados com
ferramentas de análise de dados, o que limita a exploração dos resultados obtidos com PF. Para
embasar o projeto, foram realizadas entrevistas com pesquisadores de universidades
brasileiras, investigando as aplicações da PF, os recursos utilizados para análise e as percepções
sobre o uso das visualizações gráficas nas avaliações biomecânicas. 
 Com base nos dados da PF, foram implementadas visualizações para auxiliar na análise da interpretação, 
com foco na análise do equilíbrio dos indivíduos examinados. As variáveis extraídas, principalmente o
deslocamento do Centro de Pressão, são representadas por meio de gráficos de dispersão,
mapas de calor e gráficos de violino. Cada tipo de visualização permite uma leitura distinta,
ampliando a compreensão dos dados e apoiando a tomada de decisões clínicas com maior
profundidade, complementando a análise com os métodos estatísticos convencionais.
